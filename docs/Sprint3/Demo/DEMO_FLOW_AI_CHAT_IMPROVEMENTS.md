# AI Chat 후속 개선 데모 시나리오

이 문서는 Sprint3 AI Chat 후속 개선 작업의 UX 시나리오 초안이다.

Sprint2 데모 문서는 구현 완료 기능을 QA/Test Sheet 관점으로 확인하는 성격이 강했다. Sprint3에서는 스프린트 초반 기획 기준으로, 사용자가 어떤 흐름에서 어떤 개선을 체감해야 하는지만 정리한다.

따라서 이 문서에는 세부 테스트 절차, Pass/Fail, 기술 검증 항목을 넣지 않는다. 실제 QA 항목은 구현 범위가 확정된 뒤 별도 Test Sheet에서 작성한다.

## 기준 흐름

기존 AI Chat의 큰 흐름은 유지한다.

```text
Dashboard
→ AI Chat 진입
→ 사용자 발화
→ AI 응답
→ 자막 확인
→ 대화 지속 또는 Dashboard 복귀
```

Sprint3의 목표는 이 흐름을 새로 만드는 것이 아니라, 사용자가 대화 중 느끼는 입력 명확성, 자막 타이밍, 응답 난이도, 화면 안정성을 개선하는 것이다.

## 시나리오 - CHAT-FIX-001 AI Chat Sprint2 후속 수정

사용자는 Sprint2에서 구현된 AI Chat 기본 흐름을 사용할 때, 진입 설정, 화면 회전, 대화 상태 유지 같은 기본 UX가 끊기거나 우회되지 않는 안정적인 경험을 해야 한다.

이 시나리오는 Sprint2 구현 이후 발견된 후속 수정 사항을 확인하는 흐름이다. 추가 회귀나 안정성 문제가 발견되면 같은 `CHAT-FIX-001` 흐름 안에서 하위 작업 단위로 확장한다.

관심주제를 아직 설정하지 않은 사용자는 AI Chat 최초 진입 시 관심주제 선택 다이얼로그를 먼저 확인한다. 이 단계는 필수 설정이므로 사용자가 닫기 버튼이나 외부 터치로 다이얼로그를 우회할 수 없어야 한다.

선택 중 화면을 회전해도 이미 고른 항목은 유지된다. 관심주제 저장 이후 AI Chat이 준비된 상태에서도 화면 회전 때문에 세션이 새로 시작되거나 자막 상태가 초기화되지 않아야 한다.

### 사용자 동작 순서

1. 관심주제를 아직 저장하지 않은 계정으로 Dashboard에 진입한다.
2. Dashboard에서 AI Chat 화면으로 진입한다.
3. **[Fix-001-B] 관심주제 선택 다이얼로그가 표시되는지 확인한다.**
4. **[Fix-001-B] 다이얼로그에 닫기/취소 버튼이 보이지 않는지 확인한다.**
5. 관심주제 2~3개를 선택한다.
6. 화면을 가로 방향으로 회전한다.
7. **[Fix-001-A] 화면 회전 후에도 Chat 화면 상태가 초기화되지 않는지 확인한다.**
8. **[Fix-001-B] 관심주제 다이얼로그가 선택 상태를 그대로 표시하는지 확인한다.**
9. **[Fix-001-B] 다이얼로그 목록을 스크롤해 화면 밖 항목까지 선택할 수 있는지 확인한다.**
10. 관심주제를 5개 미만으로 둔 상태에서 완료를 누른다.
11. **[Fix-001-B] 5개 선택 필요 안내 문구가 표시되는지 확인한다.**
12. 관심주제 5개를 선택하고 완료를 누른다.
13. **[Fix-001-B] 저장 성공 후 다이얼로그가 닫히고 AI Chat 화면을 계속 사용할 수 있는지 확인한다.**
14. AI Chat이 대화 가능 상태가 될 때까지 기다린다.
15. 자막을 켜고 한 턴 대화를 진행한다.
16. 화면을 가로 방향으로 회전한다.
17. **[Fix-001-A] 화면이 다시 초기 로딩부터 시작하지 않고 기존 대화 상태를 유지하는지 확인한다.**
18. **[Fix-001-A] 자막 On 상태와 마지막 자막이 유지되는지 확인한다.**
19. 다시 세로 방향으로 회전한다.
20. AI 응답 중 화면을 다시 회전한다.
21. **[Fix-001-A] AI 응답 상태가 중복 초기화되지 않고 현재 흐름을 유지하는지 확인한다.**
22. 뒤로가기로 화면을 이탈한다.
23. 녹음 또는 재생이 남지 않고 정리되는지 확인한다.

### UX 포인트

- 필수 설정 단계는 닫기/취소 UI로 우회할 수 없어야 한다.
- 화면 회전은 Chat 화면 상태를 초기화하지 않아야 한다.
- 관심주제 다이얼로그는 ViewModel의 선택 상태를 그대로 표시해야 한다.
- 가로 화면에서도 목록을 스크롤해 모든 항목에 접근할 수 있어야 한다.
- 5개 선택 정책은 사용자가 이해할 수 있는 문구로 안내되어야 한다.
- AI Chat READY 이후 화면 회전은 새 대화 시작처럼 보이지 않아야 한다.
- 자막 On/Off 상태와 마지막 자막은 유지되어야 한다.
- 화면 이탈 시에는 녹음과 재생이 정리되어야 한다.

## 시나리오 - CHAT-UX-001 Toggle-to-talk UX

사용자는 AI Chat 화면에서 마이크 버튼을 한 번 눌러 발화를 시작한다.

버튼은 사용자가 지금 녹음 중이라는 사실과, 다시 누르면 발화가 끝난다는 사실을 명확히 보여준다. 사용자는 버튼을 계속 누르고 있을 필요 없이 자연스럽게 말할 수 있고, 말을 마쳤다고 판단한 시점에 직접 정지 동작을 수행한다.

정지 후에는 입력 상태가 종료되고, 화면은 AI가 응답을 준비하거나 말하는 상태로 자연스럽게 전환된다. 사용자는 “내 말이 끝났고, 이제 AI가 답할 차례”라는 흐름을 혼동 없이 이해할 수 있어야 한다.

### 사용자 동작 순서

1. Dashboard에서 AI 대화 카드로 진입한다.
2. AI Chat 화면이 준비될 때까지 기다린다.
3. 마이크 버튼을 한 번 누른다.
4. **[개선] 버튼과 중앙 비주얼이 녹음 중 상태로 전환되는 것을 확인한다.**
5. 사용자가 학습 언어로 문장을 말한다.
6. **[개선] 녹음 중 버튼이 다시 누르면 정지되는 동작임을 확인한다.**
7. 말을 마친 뒤 마이크 버튼을 다시 누른다.
8. **[개선] 사용자 발화가 종료되고 AI 응답 대기/응답 상태로 자연스럽게 전환되는 것을 확인한다.**
9. AI 응답을 듣는다.
10. 응답이 끝난 뒤 다시 마이크 버튼으로 다음 발화를 시작한다.

### UX 포인트

- 마이크 버튼은 시작/정지의 현재 역할이 명확해야 한다.
- 녹음 중이라는 피드백은 버튼과 중앙 비주얼에서 동시에 이해 가능해야 한다.
- 발화 종료는 사용자가 직접 정지 버튼을 누르는 명시적 행동으로 처리한다.
- AI 응답으로 넘어가는 전환이 갑작스럽거나 끊겨 보이지 않아야 한다.

## 시나리오 - CHAT-UX-002 Subtitle Timing

사용자가 자막을 켠 상태에서 AI와 대화한다.

사용자가 말을 끝내면, 사용자는 먼저 자신의 발화가 자막으로 표시되는 것을 본다. 이후 AI가 응답을 시작하면 AI의 자막이 별도로 표시된다. 두 자막이 같은 시점에 한꺼번에 나타나는 것이 아니라, 대화의 실제 순서에 맞게 사용자 발화와 AI 발화가 구분되어 보인다.

사용자는 자신의 말이 앱에 인식되었는지 먼저 확인할 수 있고, 그 다음 AI의 답변을 들으며 자막을 확인할 수 있다. 자막은 전체 대화 로그처럼 길게 쌓이지 않고, 현재 대화 흐름을 이해하는 데 필요한 최신 발화 중심으로 유지된다.

### 사용자 동작 순서

1. Dashboard에서 AI Chat 화면으로 진입한다.
2. 자막 버튼을 눌러 자막을 켠다.
3. 마이크 버튼을 눌러 발화를 시작한다.
4. 사용자가 짧은 문장을 말한다.
5. 마이크 버튼을 다시 눌러 발화를 종료한다.
6. **[개선] 사용자는 AI 응답이 시작되기 전에 자신의 발화 자막을 먼저 확인한다.**
7. AI 응답이 시작된다.
8. **[개선] AI 자막은 사용자 자막과 다른 위치/역할로 구분되어 표시된다.**
9. 다음 턴을 진행한다.
10. **[개선] 자막은 전체 대화 로그처럼 누적되지 않고 현재 흐름 중심으로 유지된다.**

### UX 포인트

- 사용자 발화 자막은 AI 응답보다 먼저 확인 가능해야 한다.
- AI 자막은 사용자 자막과 역할이 구분되어야 한다.
- 자막은 대화 로그가 아니라 현재 대화 흐름을 보조하는 UI로 동작한다.
- 저장 확정이 늦더라도 화면이 비어 있거나 동시에 갱신되는 느낌을 줄여야 한다.

## 시나리오 - CHAT-TUNE-001 LangState Prompt Policy

사용자는 자신의 현재 언어 실력에 맞는 AI 응답을 받는다.

초급 사용자에게는 AI가 짧고 쉬운 문장으로 답하고, 한 번에 너무 많은 질문을 던지지 않는다. 사용자는 부담 없이 대화를 이어갈 수 있다.

조금 더 높은 수준의 사용자에게는 AI가 더 자연스러운 follow-up 질문을 던지고, 대화 주제를 조금 더 넓혀준다. 사용자는 단순 문장 반복이 아니라 자신의 수준에 맞춰 확장되는 대화를 경험한다.

언어능력 데이터가 아직 충분하지 않은 사용자에게는 안전하게 쉬운 난이도로 시작한다. 이후 대화와 교정이 쌓이면 AI 응답 난이도가 점진적으로 조정될 수 있는 기반을 마련한다.

### 사용자 동작 순서

1. 사용자가 Dashboard에서 AI Chat으로 진입한다.
2. 앱은 현재 선택 언어와 사용자의 LangState를 기준으로 대화 세션을 준비한다.
3. 사용자가 마이크 버튼을 눌러 질문이나 일상 문장을 말한다.
4. 마이크 버튼을 다시 눌러 발화를 종료한다.
5. **[개선] 초급 사용자라면 AI가 짧고 쉬운 문장으로 응답한다.**
6. **[개선] 중급 이상 사용자라면 AI가 더 자연스러운 follow-up 질문과 맥락 확장을 포함해 응답한다.**
7. 사용자가 추가 대화를 이어간다.
8. **[개선] 최근 대화 맥락이 있으면 AI가 이전 주제와 어색하게 끊기지 않게 이어간다.**

### UX 포인트

- 사용자는 자신의 수준보다 과하게 어렵거나 긴 응답을 받지 않아야 한다.
- 초급자는 짧고 명확한 응답, 중급 이상은 더 자연스러운 확장 질문을 경험해야 한다.
- 최근 대화 맥락이 있다면 AI가 같은 주제를 자연스럽게 이어갈 수 있어야 한다.
- 실력 데이터가 부족해도 대화가 불안정해지지 않고 쉬운 난이도로 시작해야 한다.
