# [Fix] CHAT-FIX-001-C 마이크 버튼 상태 UX

## User Story

사용자는 AI Chat에서 현재 마이크 버튼이 입력 시작, 입력 종료, 응답 대기 중 어떤 상태를 의미하는지 명확히 이해할 수 있다.

---

## 완료 기준(AC)

- [ ] 입력 가능 상태에서 마이크 버튼은 음성 입력 시작 동작으로 표시된다.
- [ ] 사용자가 마이크 버튼을 누르면 음성 입력이 시작되고, 버튼은 정지 버튼 형태로 바뀐다.
- [ ] 사용자가 정지 버튼을 누르면 현재 user turn이 종료된다.
- [ ] 정지 버튼 입력 후 사용자 발화 확정 대기 또는 AI 응답 대기 상태가 표시된다.
- [ ] AI 응답 중에는 마이크 버튼 형태를 유지하되 비활성화되어 새 입력을 시작할 수 없음을 알 수 있다.
- [ ] 세션 준비 전, AI 응답 중, 빠른 중복 클릭 상황에서 중복 녹음이 시작되지 않는다.

## UX 정책

마이크 버튼은 같은 위치에서 상태만 바꾼다. 버튼 위치나 역할이 크게 바뀌면 사용자가 다음 행동을 예측하기 어렵기 때문이다.

```text
입력 가능
→ 마이크 버튼 활성화
→ 클릭
→ 음성 입력 시작
→ 정지 버튼 표시
→ 클릭
→ user turn 종료
→ 사용자 발화 확정 대기 / AI 응답 대기
→ AI 응답 중
→ 마이크 버튼 비활성화
→ AI 응답 종료
→ 마이크 버튼 활성화
```

- 입력 가능 상태에서는 사용자가 바로 말할 수 있음을 보여준다.
- 녹음 중 상태에서는 다시 누르면 발화가 끝난다는 점을 정지 아이콘으로 보여준다.
- 정지 후에는 사용자가 시스템이 발화를 확정 중인지, AI 응답을 준비 중인지 알 수 있어야 한다.
- AI 응답 중에는 다음 행동이 마이크 입력이라는 맥락을 유지하되, 현재는 사용할 수 없도록 비활성화한다.

---

## 책임 경계

- `ChatScreen`: 버튼 아이콘, enabled 상태, 보조 상태 문구를 렌더링한다.
- `ChatViewModel`: 현재 입력 가능 여부, 녹음 중 여부, AI 응답 중 여부를 UI state로 제공한다.
- `ChatRepository`: user turn 종료와 realtime event 수신을 담당하며 버튼 표현을 직접 결정하지 않는다.

---

## 검증 기준

- 입력 가능 상태에서 마이크 버튼을 누르면 녹음이 시작된다.
- 녹음 중 버튼은 정지 버튼으로 표시된다.
- 정지 버튼을 누르면 user turn 종료 흐름으로 진입한다.
- 정지 버튼 이후 사용자 발화 확정 대기 또는 AI 응답 대기 상태가 보인다.
- AI 응답 중에는 마이크 버튼이 비활성화되어 새 녹음이 시작되지 않는다.
- 빠르게 여러 번 눌러도 녹음 job이 중복 생성되지 않는다.

## Edge Cases

- 세션 준비 전 마이크 클릭
- 마이크 권한 거부 후 재시도
- 녹음 시작 직후 즉시 정지
- 정지 버튼 직후 USER final transcript가 늦게 도착함
- AI 응답 중 마이크 버튼 연속 클릭
- 네트워크 오류로 녹음 또는 응답 대기 상태가 중단됨
