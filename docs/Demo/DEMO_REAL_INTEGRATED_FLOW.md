# Demo Scenario — Real 통합 흐름

> Real 계정과 Real 저장 흐름을 기준으로 발표 순서 그대로 진행하는 데모 시나리오.

---

## 시나리오 — 신규 사용자 시작

1. 앱 실행
2. Google 로그인 버튼 클릭
3. 로그인 계정 선택
4. Dashboard 진입 후 초기 설정 다이얼로그 표시 확인
5. 닉네임 입력
6. `확인` 버튼 클릭
7. 학습 언어 선택 다이얼로그 표시 확인
8. 학습 언어 선택
9. 완료 버튼 클릭
10. Dashboard 기본 카드 표시 확인

**AC**
- [ ] 로그인 성공 후 신규 사용자 초기 설정 흐름이 시작된다.
- [ ] 닉네임을 입력하고 다음 단계로 이동할 수 있다.
- [ ] 학습 언어를 선택하고 저장할 수 있다.
- [ ] Dashboard에 현재 선택 언어가 표시된다.
- [ ] 신규 사용자 기준 카드들이 Empty 또는 기본 상태로 표시된다.

---

## 시나리오 — AI Chat에서 대화 진행

1. Dashboard에서 AI 대화 카드 클릭
2. AI Chat 화면 진입 확인
3. 최초 진입 사용자라면 `Pick 5 Topics` 관심 주제 선택 다이얼로그 표시 확인
4. 관심 주제 5개 선택
5. `Done` 버튼 클릭
6. 관심 주제 다이얼로그가 닫히는지 확인
7. PTT 버튼 press
8. 최초 마이크 권한 요청이 표시되면 허용 선택
9. 사용자 발화 진행
10. 사용자 발화 중 입력 애니메이션 표시 확인
11. PTT 버튼 release
12. 녹음 상태가 종료되고 입력 애니메이션이 멈추는지 확인
13. AI 음성 응답 재생 확인
14. AI 발화 중 응답 애니메이션 표시 확인
15. 자막 버튼 클릭
16. 마지막 확정 턴 자막 표시 확인
17. 같은 방식으로 1~2턴 추가 대화
18. 뒤로가기 또는 닫기 버튼으로 Dashboard 복귀

**AC**
- [ ] AI Chat 화면에 정상 진입한다.
- [ ] 관심 주제가 없는 사용자는 최초 진입 시 관심 주제 선택 다이얼로그가 표시된다.
- [ ] 관심 주제 5개를 선택해야 저장할 수 있다.
- [ ] 관심 주제 저장 후 대화 화면을 계속 사용할 수 있다.
- [ ] 최초 마이크 권한 요청 시 허용 후 PTT 입력을 진행할 수 있다.
- [ ] PTT press 시 Recording 상태가 표시된다.
- [ ] 사용자 발화 중 입력 애니메이션이 표시된다.
- [ ] PTT release 후 Recording 상태와 입력 애니메이션이 종료된다.
- [ ] AI 음성 응답 후 다시 대기 상태로 돌아온다.
- [ ] AI 발화 중 응답 애니메이션이 표시된다.
- [ ] 자막 On 상태에서는 마지막 확정 턴 자막만 표시된다.
- [ ] 확정된 사용자 발화가 저장되어 이후 교정 흐름에서 사용할 수 있다.
- [ ] Dashboard 복귀 후 교정 대기 카드가 교정 가능 상태로 표시된다.

---

## 시나리오 — AI 대화 기반 교정 후보 확인

1. Dashboard에서 교정 대기 카드 클릭
2. Correction 화면 진입 확인
3. 교정 결과 Loading 표시 확인
4. 교정 후보 카드 표시 확인
5. 교정 전 문장 확인
6. 교정 후 문장 확인
7. 교정 설명 확인

**AC**
- [ ] 교정 가능한 대화가 있을 때 Correction 화면에 진입할 수 있다.
- [ ] 진입 후 교정 결과 생성 중 Loading 상태가 표시된다.
- [ ] 사용자가 별도 후보 추출 버튼을 누르지 않아도 교정 결과 생성이 시작된다.
- [ ] 교정 후보가 1개 이상 표시된다.
- [ ] 각 카드에서 교정 전 문장과 교정 후 문장을 구분해 확인할 수 있다.
- [ ] 교정 설명이 함께 표시된다.

## 시나리오 — 교정 결과 Flashcard 저장

1. 저장 버튼이 비활성 상태인지 확인
2. 교정 후보 카드 1개 선택
3. 선택 상태 강조 확인
4. 저장 버튼 활성화 확인
5. 저장 버튼 클릭
6. 저장 진행 상태 확인
7. 저장 완료 안내 확인
8. Dashboard 자동 복귀 확인
9. Dashboard의 Flashcard 카드 확인
10. Dashboard의 교정 대기 카드 확인

**AC**
- [ ] 선택한 교정 후보가 없으면 저장 버튼이 비활성화된다.
- [ ] 교정 후보 카드를 선택/해제할 수 있다.
- [ ] 카드 선택 시 저장 버튼이 활성화된다.
- [ ] 저장 버튼 클릭 후 저장 진행 상태가 표시된다.
- [ ] 저장 완료 시 저장된 카드 수 안내가 표시된다.
- [ ] 저장 완료 후 Dashboard로 복귀한다.
- [ ] Flashcard 저장 수 또는 복습 관련 summary가 갱신된다.
- [ ] 교정 완료 후 교정 대기 상태가 정리된다.

## 시나리오 — 통계 화면에서 학습 지표 확인

1. Dashboard에서 통계 카드 클릭
2. Statistics 화면 진입 확인
3. 지표 요약 카드 5개 확인
4. 어휘 레벨 카드 값 확인
5. 표현 폭 카드 값 확인
6. 문법 정확도 카드 값 확인
7. 유창성 카드 값 확인
8. 자연스러움 카드 값 확인

**AC**
- [ ] Statistics 화면에 정상 진입한다.
- [ ] 현재 선택 언어 기준 지표 카드가 표시된다.
- [ ] 어휘 레벨이 초기값에만 고정되지 않는다.
- [ ] 표현 폭이 0에만 고정되지 않는다.
- [ ] 문법 정확도, 유창성, 자연스러움 값이 표시된다.

---

## 시나리오 — 통계 지표 차트 확인

1. Statistics 화면에서 표현 폭 카드 클릭
2. 차트 다이얼로그 표시 확인
3. 차트 요약 정보 확인
4. line chart 표시 확인
5. 차트의 포인트 클릭
6. 선택 포인트의 값과 변화량 marker 표시 확인
7. 차트 닫기
8. 다른 지표 카드 클릭
9. 해당 지표 기준 차트로 변경되는지 확인

**AC**
- [ ] 지표 카드 클릭 시 차트 다이얼로그가 열린다.
- [ ] 선택한 지표명이 차트에 반영된다.
- [ ] 차트 요약 정보가 지표 값과 함께 표시된다.
- [ ] 기록이 충분하면 line chart가 표시된다.
- [ ] 포인트 클릭 시 해당 포인트 기준 marker 정보가 표시된다.
- [ ] 기록이 부족하면 Empty 상태로 표시되며 화면이 실패하지 않는다.
- [ ] 다른 지표 클릭 시 해당 지표 기준으로 차트가 갱신된다.

---

## 시나리오 — 저장된 Flashcard 학습

1. Dashboard에서 Flashcard 학습 카드 클릭
2. SRS 학습 화면 진입 확인
3. 복습 가능한 Flashcard 표시 확인
4. 현재 카드 진행 표시 확인
5. 카드 앞면 확인
6. 카드 클릭 또는 뒤집기 조작
7. 카드 뒷면 확인
8. 스피커 버튼 클릭
9. 뒷면 문장 발음 재생 확인
10. `Again / Hard / Good / Easy` 중 하나 선택
11. 확인 또는 다음 진행 버튼 클릭
12. 다음 카드 또는 완료 상태 확인

**AC**
- [ ] Flashcard 학습 화면에 정상 진입한다.
- [ ] 현재 복습 가능한 Flashcard가 학습 대상으로 표시된다.
- [ ] 현재 카드가 전체 학습 카드 중 몇 번째인지 확인할 수 있다.
- [ ] 카드 앞면과 뒷면을 확인할 수 있다.
- [ ] 뒷면 문장의 발음을 재생할 수 있다.
- [ ] `Again / Hard / Good / Easy` 4단계 중 하나로 복습 결과를 입력할 수 있다.
- [ ] 복습 입력 후 다음 복습 가능한 Flashcard 또는 완료 상태가 표시된다.

## 시나리오 — Dashboard 재진입 후 통합 상태 확인

1. SRS 또는 Statistics 화면에서 Dashboard로 복귀
2. 상단 학습 언어 selector의 현재 언어 확인
3. 최근 AI 대화 카드 확인
4. 교정 대기 카드 확인
5. Flashcard 학습 카드 확인
6. 통계 카드 확인
7. 필요 시 학습 언어 selector 클릭
8. 학습 언어 선택 다이얼로그 표시 확인
9. 다른 학습 언어 선택
10. 완료 버튼 클릭
11. Dashboard의 현재 언어 표시와 카드 요약이 선택 언어 기준으로 바뀌는지 확인
12. AI Chat 또는 Statistics 화면에 진입해 변경된 학습 언어 기준 화면인지 확인
13. AI Chat → Correction → Flashcard → Statistics 흐름이 하나의 학습 사이클로 이어졌는지 확인

**AC**
- [ ] Dashboard는 현재 선택 언어 기준으로 요약 카드를 표시한다.
- [ ] 학습 언어 selector를 통해 현재 선택 언어를 확인할 수 있다.
- [ ] 학습 언어 선택 다이얼로그에서 다른 언어를 선택할 수 있다.
- [ ] 언어 변경 후 Dashboard의 현재 언어 표시가 갱신된다.
- [ ] 언어 변경 후 카드 요약이 이전 언어 값으로 남지 않는다.
- [ ] 주요 화면 진입 시 변경된 학습 언어 기준으로 화면이 열린다.
- [ ] 최근 AI 대화 카드가 표시되고, 대화 시간 또는 주제 값이 있는 경우 해당 칩이 표시된다.
- [ ] 최근 대화 topic이 없을 경우 fallback 표시가 어색하지 않다.
- [ ] 교정 완료 후 교정 대기 상태가 정리되어 있다.
- [ ] Flashcard 카드에 저장 또는 복습 관련 값이 반영된다.
- [ ] 언어 성취율 카드에 학습 지표 변화가 반영된다.
- [ ] 사용자가 다음 학습 행동으로 자연스럽게 이동할 수 있다.
