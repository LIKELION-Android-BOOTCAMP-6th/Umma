## 시나리오 — AI Chat에서 대화 진행

1. Dashboard에서 AI 대화 카드 클릭
2. AI Chat 화면 진입 확인
3. 최초 진입 사용자라면 `Pick 5 Topics` 관심 주제 선택 다이얼로그 표시 확인
4. 관심 주제 5개 선택
5. `Done` 버튼 클릭
6. 관심 주제 다이얼로그가 닫히는지 확인
7. PTT 버튼 press
8. 최초 마이크 권한 요청이 표시되면 허용 선택
9. 사용자 발화 진행
10. 사용자 발화 중 입력 애니메이션 표시 확인
11. PTT 버튼 release
12. 녹음 상태가 종료되고 입력 애니메이션이 멈추는지 확인
13. AI 음성 응답 재생 확인
14. AI 발화 중 응답 애니메이션 표시 확인
15. 자막 버튼 클릭
16. 마지막 확정 턴 자막 표시 확인
17. 같은 방식으로 1~2턴 추가 대화
18. 뒤로가기 또는 닫기 버튼으로 Dashboard 복귀

- [ ] AC1: AI Chat 화면에 정상 진입한다.
- [ ] AC2: 관심 주제가 없는 사용자는 최초 진입 시 관심 주제 선택 다이얼로그가 표시된다.
- [ ] AC3: 관심 주제 5개를 선택해야 저장할 수 있다.
- [ ] AC4: 관심 주제 저장 후 대화 화면을 계속 사용할 수 있다.
- [ ] AC5: 최초 마이크 권한 요청 시 허용 후 PTT 입력을 진행할 수 있다.
- [ ] AC6: PTT press 시 Recording 상태가 표시된다.
- [ ] AC7: 사용자 발화 중 입력 애니메이션이 표시된다.
- [ ] AC8: PTT release 후 Recording 상태와 입력 애니메이션이 종료된다.
- [ ] AC9: AI 음성 응답 후 다시 대기 상태로 돌아온다.
- [ ] AC10: AI 발화 중 응답 애니메이션이 표시된다.
- [ ] AC11: 자막 On 상태에서는 마지막 확정 턴 자막만 표시된다.
- [ ] AC12: 확정된 사용자 발화가 저장되어 이후 교정 흐름에서 사용할 수 있다.
- [ ] AC13: Dashboard 복귀 후 교정 대기 카드가 교정 가능 상태로 표시된다.
