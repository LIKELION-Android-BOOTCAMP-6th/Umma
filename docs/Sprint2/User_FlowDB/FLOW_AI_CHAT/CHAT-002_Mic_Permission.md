# [Feature] CHAT-002 마이크 권한 및 입력 준비

## User Story

사용자는 AI Chat 화면에서 마이크 권한 상태를 확인하고, 권한이 허용된 경우 PTT 입력을 시작할 수 있다.

---

# 완료 기준(AC) (Acceptance Criteria)

- [ ] AI Chat 화면에서 마이크 권한 상태를 확인한다.
- [ ] 권한이 허용된 경우 PTT 버튼이 사용 가능 상태가 된다.
- [ ] 권한이 거부된 경우 안내 UI를 표시한다.
- [ ] 권한 요청 중에는 중복 요청을 방지한다.
- [ ] 권한 거부 상태에서도 앱이 크래시되지 않는다.
- [ ] 권한 확인은 세션 진입 상태와 분리해서 관리한다.

# Details

## 권한 역할

마이크 권한은 AI Chat 화면이 열리는 조건이 아니라, 음성 입력을 시작하기 위한 조건이다.
권한이 없어도 화면 진입은 가능해야 하며, 사용자가 입력을 시도할 때 명확한 안내를 제공한다.

## 상태 정책

- 권한 허용: PTT 버튼 활성화
- 권한 거부: 안내 UI와 재요청 경로 표시
- 권한 요청 중: 버튼 중복 클릭 방지

---

# 기술 설계 가이드

## 권장 구조

```text
presentation/chat/
→ ChatScreen
→ ChatViewModel
→ MicPermissionState
```

권한 상태는 `Recording`이나 `AIState`와 섞지 않는다.
권한은 입력 가능 여부를 결정하고, 실제 오디오 스트림은 `CHAT-003`에서 다룬다.

---

# 검증 기준

- 권한 허용 전에는 PTT 입력이 시작되지 않는다.
- 권한 허용 후 PTT 버튼이 활성화된다.
- 권한 거부 시 사용자에게 다시 시도 가능한 안내가 표시된다.

---

# Edge Cases

- 사용자가 권한 팝업을 닫음
- 권한을 영구 거부함
- 권한 요청 중 화면을 이탈함
- 권한 상태 변경 후 화면에 다시 진입함
