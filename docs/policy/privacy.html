개인정보처리방침

Umma는 AI 기반 언어 학습 보조 앱입니다. 이 문서는 Umma가 서비스 제공을 위해 어떤 정보를 처리하는지 설명합니다.

1. 운영자와 문의

운영자: LastDance

문의 이메일: umma.app.kr@gmail.com

2. 처리하는 정보

Umma는 기능 제공과 학습 경험 개선을 위해 다음 정보를 처리할 수 있습니다.

  • 사용자 계정 식별자와 Google 로그인 정보
  • primaryLang, selectedLang 등 학습 언어 설정
  • 음성 입력 또는 음성에서 생성된 transcript
  • AI Chat 응답 transcript와 최근 대화 맥락
  • 교정 후보, 교정 결과, 설명
  • Flashcard 앞면, 뒷면, 설명
  • SRS 학습 기록: nextReviewAt, interval, easeFactor, lastReviewRating, lastReviewedAt
  • LangState, DashSummary, FlashcardSummary, 통계 history
  • AI 콘텐츠 신고 데이터와 신고 시점 기준 최근 6턴 대화 컨텍스트 snapshot
  • 앱 버전, 모델 버전, prompt version 등 운영 추적 정보
  • 푸시 알림 토큰, 알림 수신 설정, 마케팅 알림 수신 동의 상태

3. 처리 목적

  • 계정 정보: 로그인, 사용자 데이터 구분, 계정 삭제 처리
  • 언어 설정: 사용자의 학습 언어와 설명 언어 설정
  • 음성 및 transcript: AI 대화, 교정 후보 추출, 언어 학습 지원
  • AI 응답: 대화 화면 표시, 교정, 신고 검토, 품질 개선
  • Flashcard와 SRS 기록: 반복 학습 제공, 다음 복습 시점 계산, 학습 통계 표시
  • 신고 데이터: 부적절한 AI 생성 콘텐츠 검토와 prompt/filter 정책 개선
  • 운영 추적 정보: 오류 분석, 모델 또는 prompt 변경 이력 확인
  • 알림 정보: 복습 알림, 서비스 공지, 마케팅 또는 프로모션 알림 발송과 수신 설정 관리

4. 알림과 마케팅 안내

Umma는 사용자의 수신 설정에 따라 복습 알림, 서비스 공지, 마케팅 또는 프로모션 알림을 보낼 수 있습니다.

마케팅 알림은 사용자의 동의 또는 기기 알림 설정에 따라 관리되며, 사용자는 앱 또는 운영체제 설정에서 알림 수신을 변경할 수 있습니다.

5. 저장과 전송

사용자의 학습 데이터는 앱의 로컬 저장소와 Firebase 기반 서버 저장소에 저장될 수 있습니다. 네트워크가 불안정한 경우 일부 데이터는 로컬에 먼저 저장된 뒤 나중에 동기화될 수 있습니다.

AI Chat, transcript, 교정 요청 등 AI 기능에 필요한 정보는 기능 제공을 위해 AI 제공자에게 전송될 수 있습니다. Umma는 서비스 제공과 안전 운영에 필요한 범위에서만 데이터를 처리하도록 설계합니다.

전송은 가능한 경우 HTTPS 등 암호화된 통신을 사용합니다.

6. 신고 데이터

사용자가 AI 응답을 신고하면 신고된 응답, 신고 시점의 최근 6턴 대화 컨텍스트 snapshot, 앱 버전, 모델 버전, prompt version 등 운영 검토에 필요한 정보가 저장될 수 있습니다.

신고 데이터는 기본적으로 신고 접수일 기준 1년 동안 보관합니다. 법적 요구, 정책 위반 조사, abuse 방지 등 정당한 사유가 있는 경우 일부 정보는 더 오래 보관되거나 비식별화될 수 있습니다.

7. 보관과 삭제

사용자는 앱 내 회원탈퇴 기능 또는 공개 계정 삭제 요청 경로를 통해 계정 삭제를 요청할 수 있습니다. 계정 삭제 요청은 umma.app.kr@gmail.com으로도 보낼 수 있습니다.

계정 삭제 시 Firebase Auth 계정과 users/{uid} 하위 사용자 데이터 삭제를 기준으로 처리합니다. 다만 운영 검토가 필요한 신고 데이터, 보안 로그, Cloud Functions 로그 등은 법적 또는 운영 목적에 따라 삭제, 보관 또는 비식별화될 수 있습니다.

8. 정책 변경

서비스 기능, 데이터 처리 방식, 법령 또는 플랫폼 정책이 변경되면 이 개인정보처리방침도 변경될 수 있습니다. 중요한 변경이 있는 경우 앱 또는 공개 페이지를 통해 안내합니다.
